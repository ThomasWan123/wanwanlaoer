# IARC 内容分级 · 填写指南（三国塔防）

在 Play Console → **应用内容 → 内容分级** → 开始 IARC 问卷。

## 游戏概况（供问卷参考）

| 项 | 本游戏情况 |
|----|-----------|
| 类型 | 塔防 / 策略 |
| 视角 | 2D 俯视 |
| 暴力 | 卡通风格战斗，无写实血腥、无断肢 |
| 语言 | 中文，无粗俗用语 |
| 恐怖 | 无 |
| 赌博 | 无 |
| 内购 | 无 |
| 广告 | 无 |
| 用户生成内容 | 无 |
| 社交 / 聊天 | 无 |
| 联网 | 玩法不依赖联网 |

## 建议勾选倾向

- **暴力**：有卡通/幻想暴力，程度**低～中**（塔防射杀敌军）
- **血腥**：**无**或**非常轻微**（非写实）
- **性内容**：无
- **语言**：无不当语言
- **恐怖**：无
- **赌博**：无
- **药物**：无
- **付费**：免费，无应用内购买

## 预期评级（仅供参考）

多数地区约为 **Everyone / 3+ / 12+** 一档（因卡通战斗），以 IARC 最终结果为准。

## 注意

- 如实填写，勿隐瞒战斗元素
- 若未来加入广告或 IAP，需**重新填写**并更新数据安全表单
