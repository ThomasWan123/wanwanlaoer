# Play 控制台 · 数据安全表单（本游戏参考答案）

> 与 [PRIVACY.md](../../PRIVACY.md) 保持一致。在 Play Console → **应用内容 → 数据安全** 中按下列选择填写。

## 总览

| 问题 | 答案 |
|------|------|
| 应用是否收集或共享用户数据？ | **否**（不收集、不共享） |
| 所有数据是否加密传输？ | 不适用（无上传） |
| 是否提供删除数据的方式？ | **是** — 卸载应用或系统「清除数据」 |

## 数据类型（逐项）

以下全部选 **不收集**：

- 位置
- 个人信息（姓名、邮箱、用户 ID 等）
- 财务信息
- 健康与健身
- 消息
- 照片与视频
- 音频
- 文件与文档
- 日历
- 联系人
- 应用活动（页面浏览、应用内搜索等）— **若控制台强制区分「分析」：仍选不收集**
- 网页浏览
- 应用信息与性能（崩溃日志、诊断）— **本包未集成 Firebase/Crashlytics：选不收集**
- 设备 ID 或其他 ID

## 本地存储说明（可选备注）

应用使用 WebView `localStorage` 在**设备本地**保存战役进度与设置，**不上传**至开发者服务器。这在数据安全表单中通常**不算「收集」**（数据不离开设备），与 Google 对纯本地存储的说明一致。

## 第三方 SDK

当前 Release 包**未集成**广告、分析、社交登录 SDK。

## 权限对照

| 权限 | 声明 |
|------|------|
| `VIBRATE` | 大招/操作触觉反馈，不涉及个人数据 |

Manifest 中**无** `INTERNET` 权限（游戏资源均打包在 APK 内）。
