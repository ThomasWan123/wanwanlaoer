# 隐私政策 URL（Play Console 用）

## 请粘贴到 Play Console 的链接

仓库为 **公开** 且已推送 `PRIVACY.md` 后，使用下列 URL 之一（按你仓库实际目录选择）：

### 若仓库根目录就是 `AndroidVer` 项目

```
https://github.com/ThomasWan123/wanwanlaoer/blob/main/PRIVACY.md
```

### 若 `AndroidVer` 在仓库子目录下

```
https://github.com/ThomasWan123/wanwanlaoer/blob/main/AndroidVer/PRIVACY.md
```

默认分支不是 `main` 时，将 URL 中的 `main` 改为 `master` 等实际分支名。

## 上架前自检

1. 仓库 **Settings → General → Change visibility** 为 **Public**
2. 无痕窗口打开上述链接，确认能直接阅读全文
3. Play Console → **商店详情 → 隐私政策** 粘贴同一 URL
